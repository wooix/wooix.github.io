시험 공부를 할 때 “정답은 3번”이라는 말만 듣는 것과 “2번도 그럴듯하지만 이 조건 때문에 3번이 더 맞다”는 설명을 듣는 것은 다릅니다. 정답 이외의 후보를 얼마나 비슷하게 보는지에도 배울 정보가 있을 수 있습니다.

<strong>Knowledge Distillation(지식 증류)</strong>의 기본 아이디어는 큰 모델의 출력에서 학습 신호를 얻어 더 작은 모델을 가르치는 것입니다. 2015년 논문은 <strong>Soft Targets(부드러운 목표 분포)</strong>를 활용해 후보 답 사이의 관계를 전달합니다. [원 논문, §1–2](https://arxiv.org/html/1503.02531v1#S2)

> <strong>읽기 기준</strong> · Hinton, Vinyals, Dean의 논문은 <strong>2015년 3월 9일</strong> arXiv에 공개되었습니다. 선행 모델 압축 연구를 발전시킨 논문이며, 오늘의 LLM(대규모 언어 모델) 추론 성능을 직접 검증한 논문은 아닙니다. [논문 정보](https://arxiv.org/abs/1503.02531)

## Teacher–Student: 정답 이외에도 배울 정보가 있을까

<strong>Teacher Model(교사 모델)</strong>은 학습 목표를 제공하고, <strong>Student Model(학생 모델)</strong>은 이를 배웁니다. 교사가 정답 후보에 부여하는 확률 전체를 사용하면, 정답 표시 하나에 담기지 않는 후보 간 유사성이 학습 신호에 포함됩니다. [원 논문, §1](https://arxiv.org/html/1503.02531v1#S1)

아래는 직관을 위한 가상 분류 예시입니다. 실제 논문의 측정값은 아닙니다.

| 학습 목표 | 참새 | 비둘기 | 자동차 |
| --- | --- | --- | --- |
| Hard Target(단단한 정답 표시) | 100% | 0% | 0% |
| Soft Target(부드러운 목표 분포) | 70% | 25% | 5% |

두 줄 모두 참새를 가장 높은 후보로 둡니다. 하지만 둘째 줄은 비둘기를 자동차보다 비슷한 후보로 본다는 정보도 갖습니다. 학생이 단순히 “참새”라는 이름을 외우는 것과, 어떤 후보를 혼동하기 쉬운지까지 배우는 차이로 읽을 수 있습니다.

이 비유를 언어 모델에 가져갈 때는 조심할 부분이 있습니다. 후보의 확률을 배우는 것과 교사가 문장으로 쓴 풀이를 읽는 것은 제공받는 신호가 다릅니다. 새 증류 논문을 읽을 때 <strong>학생이 실제로 받는 데이터가 무엇인지</strong>부터 적어 보겠습니다.

## Temperature: 작은 확률의 차이를 드러내기

원 논문은 Softmax(소프트맥스)에 <strong>Temperature(온도)</strong>를 적용해 출력 분포를 부드럽게 만듭니다. 온도를 높이면 최고 후보에 몰린 확률이 완화됩니다. 교사와 학생에 같은 학습 온도를 사용하고, 정답 레이블을 활용하는 손실을 함께 둘 수도 있습니다. 두 손실을 섞을 때는 온도에 따른 기울기 크기 변화를 보정하기 위해 증류 항에 온도의 제곱을 곱하는 설명이 나옵니다. [원 논문, §2](https://arxiv.org/html/1503.02531v1#S2)

시험의 답 하나만 굵게 표시한 자료에서 다른 후보에 관한 작은 메모까지 읽기 좋게 만드는 비유를 떠올려 봅시다. 다만 글씨를 모두 같은 굵기로 만들면 강조 자체가 사라지듯, 온도를 높이는 조작이 무조건 좋은 결과를 뜻하지는 않습니다.

실험 노트에서는 <strong>Temperature(온도)</strong>를 조절했을 때 무엇이 바뀌는지 먼저 확인하면 좋습니다. 목표 분포를 바꾸는지, 출력 문장을 생성하는 무작위성을 바꾸는지 구분해 적습니다. 이 노트의 온도 설명은 증류 학습에서 목표 분포를 만드는 문맥입니다.

## Evidence: 2015년 논문이 보여준 것

논문은 MNIST 분류와 음성 인식 등의 실험을 통해, 큰 모델 또는 Ensemble(앙상블)의 지식을 하나의 모델로 옮기는 접근을 평가했습니다. Ensemble(앙상블)은 여러 모델의 예측을 결합하는 방식입니다. 이 연구의 결과만으로 현대 SLM(소형 언어 모델)의 수학 추론이나 장문 생성 능력까지 입증됐다고 말할 수는 없습니다. [원 논문, §3–5](https://arxiv.org/html/1503.02531v1#S3)

그래서 이 글은 다음 연구를 읽기 위한 기준점으로 사용합니다. “교사의 무엇을 전달했는가”, “학생이 어떤 과제에서 배웠는가”, “동일한 학생을 직접 학습했을 때보다 무엇이 달라졌는가”라는 질문을 얻는 것이 목적입니다.

원 논문의 기여와 현재 관심사를 연결하되, 둘 사이의 실험이 비어 있다면 그 자리를 연구 질문으로 남겨 두겠습니다.

## SLM: 성능 향상을 어떤 조건에서 말할까

아래는 SLM(소형 언어 모델) 증류 연구를 읽기 위한 비교 틀입니다. 특정 후속 논문의 결론을 요약한 표는 아닙니다.

| 비교 항목 | 확인할 질문 |
| --- | --- |
| Teacher Signal(교사 신호) | 전체 확률, 일부 후보 확률, 생성된 문장 중 무엇을 제공하는가? |
| Student Capacity(학생 용량) | 같은 크기의 학생 모델을 기준선으로 비교했는가? |
| Training Data(학습 데이터) | 증류 방법 외에 데이터량과 품질도 달라졌는가? |
| Training Budget(학습 예산) | 교사 출력 생성과 학생 학습 비용을 함께 기록했는가? |
| Evaluation(평가) | 외운 문항과 새로운 유형을 구분했는가? |

예를 들어 증류 모델이 더 높은 점수를 받았더라도 학습 예시가 훨씬 많았다면, 무엇이 개선을 만들었는지 분리하는 실험이 필요합니다. 반대로 같은 예산에서 특정 과제를 더 잘한다면 자신의 사용 목적과 그 과제가 얼마나 닮았는지 살펴볼 수 있습니다.

이러한 읽기 방식은 “작은 모델이 큰 모델만큼 좋아졌다”는 큰 표현을 구체적인 모델, 데이터, 과제의 문장으로 바꾸는 데 도움이 됩니다.

## Research Questions: 작게 시작할 증류 실험

연구 보조용 SLM(소형 언어 모델)을 만든다면, 논문 요약 전체를 한 번에 맡기기보다 먼저 좁은 과제를 정의해 볼 수 있습니다. 다음은 이 글의 실험 제안이며 실제 측정 결과는 아닙니다.

1. 원문에서 <strong>Claim(주장)</strong>과 <strong>Evidence(근거)</strong>를 구분하는 짧은 과제를 정합니다.
2. 평가할 논문을 먼저 분리하고, 교사의 학습 예시 생성에 그 평가 문서를 사용하지 않도록 관리합니다.
3. 같은 학생 모델에서 사람이 만든 예시만 쓴 조건과 교사 신호를 추가한 조건을 비교합니다.
4. 정확도와 함께 근거 없는 단정, 원문 조건 누락, 영어(한글) 표기 유지 여부를 기록합니다.
5. 교사가 틀린 사례를 따로 모아 학생에게도 같은 오류가 나타나는지 확인합니다.

실험의 끝에서 보고 싶은 것은 교사의 문장을 얼마나 닮았느냐만이 아닙니다. 자신이 고른 과제에서 실제로 더 정확하고 일관된 답을 주는지를 확인하고 싶습니다.

## Vocabulary: 작은 모델을 설명하는 단어

| 영어 용어 | 한글 보조 설명 |
| --- | --- |
| Knowledge Distillation | 지식 증류, 교사 모델의 출력 등을 학생의 학습 신호로 사용하는 것 |
| Teacher Model | 교사 모델, 학습 목표를 제공하는 모델 |
| Student Model | 학생 모델, 교사의 신호를 활용해 학습하는 모델 |
| Soft Targets | 부드러운 목표 분포, 후보마다 정도를 부여한 학습 목표 |
| Temperature | 온도, 확률분포의 날카로움을 조절하는 값 |
| Ensemble | 앙상블, 여러 모델의 예측을 결합하는 방식 |

Knowledge Distillation(지식 증류)을 읽을 때는 학생이 받아 적은 정답뿐 아니라 <strong>어떤 추가 정보를 받았는지</strong>를 찾아보겠습니다. 그 정보가 실제 과제 성능으로 이어졌는지를 확인하는 것이 SLM(소형 언어 모델) 연구의 다음 질문입니다.
