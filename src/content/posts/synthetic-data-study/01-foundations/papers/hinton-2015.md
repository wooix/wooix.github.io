[1강으로 돌아가기](/notes/synthetic-data-study/01-foundations/)

검토 원문: [arXiv v1, 2015-03-09](https://arxiv.org/pdf/1503.02531v1). 초록과 아래 본문 전체를 확인했으며 참고문헌 목록은 요약에서 제외했다.

## 초록

Distillation(증류)은 큰 모델이나 Ensemble(앙상블)의 예측 정보를 배포하기 쉬운 단일 모델로 옮기는 방법이다. 논문은 숫자 인식과 음성 인식에서 이를 실험하고, 혼동하기 쉬운 클래스에 집중하는 Specialist(전문 모델)도 제안한다. 여기서 생성되는 핵심 학습 신호는 새 입력이 아니라 교사의 출력 분포다.

## 1 서론

학습은 많은 계산을 써서 구조를 발견해야 하지만 배포는 응답 지연과 계산량이 제한된다. 저자는 지식을 매개변수 자체가 아니라 입력에서 출력으로의 대응으로 보면, 다른 구조의 모델에 전달할 수 있다고 설명한다.

교사가 오답 클래스에 배정한 작은 확률에도 클래스 간 유사성이 담겨 있다. Soft Target(연성 목표)은 이 분포를 제공하고, Hard Target(경성 목표)은 정답 클래스 하나만 제공한다. 전이 데이터는 기존 학습 입력이나 라벨 없는 입력이어도 된다. 따라서 본 논문의 Distillation과 입력까지 만드는 합성 데이터 생성을 구분해 읽어야 한다.

## 2 증류

Softmax(소프트맥스)에 Temperature(온도) T를 적용하면 각 Logit(로짓)을 T로 나눈 뒤 확률로 정규화한다. T를 높이면 분포가 완만해져 작은 클래스 확률의 관계가 더 잘 드러난다. 학생도 같은 T로 교사 분포를 맞추고, 배포할 때는 $T=1$을 사용한다.

정답이 있다면 높은 T에서 Soft Target과의 Cross-Entropy(교차 엔트로피), $T=1$에서 Hard Target과의 Cross-Entropy를 가중 결합한다. Soft Target의 Gradient(기울기) 크기가 대략 $1/T^2$로 줄어들므로 $T^2$를 곱해, T를 바꾸었을 때 두 학습 신호의 상대적 크기가 급변하지 않도록 한다. [원문 §2](https://arxiv.org/pdf/1503.02531v1)

### 2.1 Logit 맞추기는 증류의 특수한 경우

T가 Logit 크기보다 충분히 크고 입력별 Logit 평균이 0이면, Distillation의 Gradient는 학생과 교사 Logit의 차이에 비례한다. 이 조건에서 Logit의 제곱 오차를 줄이는 방법과 연결된다. 낮은 T는 매우 작은 확률의 클래스에 덜 집중한다. 저자는 그 정보가 유용한지 잡음인지는 실험 문제이며, 작은 학생에서는 중간 T가 더 좋을 수 있다고 설명한다.

## 3 MNIST 예비 실험

큰 모델이 얻은 일반화 특성을 작은 모델이 Soft Target으로 배울 수 있는지 확인한다. MNIST에서 두 은닉층에 각각 1,200개 유닛을 둔 교사는 시험 오류 67개, 각각 800개 유닛의 일반 학습 학생은 146개, T=20의 Soft Target을 활용한 학생은 74개를 기록했다. 교사는 입력 이동 등의 규제를 사용했고 학생 전이 데이터에는 그 이동을 넣지 않았다는 조건이 중요하다.

일부 숫자 클래스를 전이 데이터에서 제외하는 실험도 제시한다. 다만 보고된 일부 개선은 시험 성능을 최대화하도록 클래스 편향을 조정한 결과다. 이를 독립 검증된 일반화 성능이나 보지 못한 개념을 완전히 새로 획득한 증거로 확대해서는 안 된다. [원문 §3](https://arxiv.org/pdf/1503.02531v1)

## 4 음성 인식 실험

음성의 짧은 구간에서 Hidden Markov Model(은닉 마르코프 모형)의 상태 확률을 예측하는 음향 모델을 대상으로 한다. 이 절은 작은 숫자 인식 실험에서 실제 사용되는 규모의 모델로 검증 범위를 넓힌다. 학습은 프레임별 상태 분류를 최적화하지만 최종 사용 목적은 단어 인식이다.

### 4.1 결과

같은 구조의 모델 10개를 서로 다르게 초기화한 Ensemble을 단일 모델로 옮긴다. 표 1에서 프레임 정확도는 기준 모델 58.9%, Ensemble 61.1%, Distillation 모델 60.8%이며 Word Error Rate(단어 오류율)는 각각 10.9%, 10.7%, 10.7%다. 프레임 분류 개선과 단어 수준 개선 크기가 다른 것은 학습 목적과 최종 평가의 차이를 보여준다. [원문 §4.1, 표 1](https://arxiv.org/pdf/1503.02531v1)

**Table 1. 음향 모델의 프레임 정확도와 단어 오류율** ([원문](https://arxiv.org/pdf/1503.02531v1))

| 시스템 | 시험 프레임 정확도 | WER |
| --- | --- | --- |
| 기준 모델 | 58.9% | 10.9% |
| 10개 Ensemble | 61.1% | 10.7% |
| Distillation 단일 모델 | 60.8% | 10.7% |

프레임 정확도는 높을수록, WER는 낮을수록 좋다. 같은 크기의 단일 모델이 Ensemble의 개선 상당 부분을 전달받지만 프레임 정확도와 최종 단어 오류율은 서로 다른 평가 수준이다.


## 5 매우 큰 데이터셋에서 전문 모델 Ensemble 학습

전체 모델을 여러 개 학습하기 어려운 경우, 이미 학습한 범용 모델에서 출발해 혼동되는 일부 클래스에 집중하는 Specialist를 만든다. 이 절의 핵심은 배포 압축 이전에, 큰 데이터에서 Ensemble을 만드는 학습 비용 문제를 줄이는 것이다.

### 5.1 JFT 데이터셋

JFT는 당시 구글 내부의 대규모 이미지 데이터셋이다. 이미 장기간 학습한 기준 모델이 있어도 전체 Ensemble을 새로 만드는 비용이 크기 때문에, 기존 모델을 이용하는 Specialist 접근의 동기를 제공한다.

### 5.2 전문 모델

범용 모델의 가중치로 초기화하고 전문 클래스에 속한 예제와 나머지 예제를 섞어 학습한다. 관심 없는 클래스는 하나의 기타 클래스로 합쳐 출력 크기를 줄인다. 전문 클래스의 비율을 인위적으로 높였으므로 추론에서는 기타 클래스의 Logit을 보정한다.

### 5.3 클래스의 전문 모델 배정

범용 모델이 함께 예측하는 클래스들을 예측값의 공분산으로 묶는다. 이는 단순히 입력이 비슷한 집단보다 모델이 구별하기 어려운 클래스 집합을 찾으려는 절차다. 이 집단을 정하는 과정에는 정답 라벨이 필요하지 않다.

### 5.4 전문 모델 Ensemble 추론

범용 모델의 상위 예측과 관련된 Specialist만 활성화한다. 이후 범용 분포와 활성 Specialist 분포에 대한 Kullback–Leibler Divergence(쿨백–라이블러 발산)의 합을 줄이는 전체 분포를 찾는다. Specialist의 기타 클래스에는 전체 분포에서 해당 클래스들의 확률을 합쳐 대응시킨다. 논문에서는 이 최적화를 이미지마다 수행한다.

### 5.5 결과

JFT에서 범용 모델에 61개 Specialist를 결합하면 표 3의 전체 Top-1 정확도가 25.0%에서 26.1%로 높아진다. 여러 Specialist가 한 클래스를 담당하는 경우의 결과도 나눈다. 이것은 Specialist Ensemble의 결과이며, Specialist 정보를 다시 단일 모델에 Distillation한 결과는 아니다. [원문 §5.5](https://arxiv.org/pdf/1503.02531v1)

**Table 3. JFT에서 Specialist를 결합한 Top-1 정확도** ([원문](https://arxiv.org/pdf/1503.02531v1))

| 시스템 | 전문 클래스 조건부 정확도 | 전체 정확도 |
| --- | --- | --- |
| 기준 모델 | 43.1% | 25.0% |
| 61개 Specialist 결합 | 45.9% | 26.1% |

조건부 열은 전문 클래스에 속하는 예제와 해당 예측 범위만 고려한 값이다. 전체 열과 분모·평가 범위가 다르므로 직접 비교하지 않는다. 이 표는 Specialist 결합 성능이며 단일 모델로 재증류한 결과가 아니다.


## 6 정규화 역할을 하는 Soft Target

전체 데이터로 학습한 교사가 만든 Soft Target을 이용하면, 작은 전이 데이터에도 교사가 발견한 규칙성을 담을 수 있는지 확인한다. 음향 모델 학습 데이터의 3%만 사용한 표 5에서 Hard Target은 시험 프레임 정확도 44.5%, Soft Target은 57.0%다. 전체 데이터 기준 모델은 58.9%이며, 교사는 전체 데이터를 사용했다. 따라서 원래 데이터 요구량이 아무 조건 없이 3%로 줄었다는 의미가 아니다.

**Table 5. 같은 음향 모델에서 학습 자료와 목표 형태 비교** ([원문](https://arxiv.org/pdf/1503.02531v1))

| 학습 조건 | 학습 프레임 정확도 | 시험 프레임 정확도 |
| --- | --- | --- |
| 전체 데이터·Hard Target | 63.4% | 58.9% |
| 3% 데이터·Hard Target | 67.3% | 44.5% |
| 3% 데이터·Soft Target | 65.4% | 57.0% |

3% 데이터와 Hard Target에서는 학습·시험 격차가 크다. Soft Target을 사용하면 시험 정확도가 전체 데이터 기준에 가까워진다. 그러나 Soft Target을 만드는 교사는 전체 데이터로 학습했으므로 원래 지식 획득 비용이 사라진 결과는 아니다.


### 6.1 전문 모델의 과적합을 막는 Soft Target

Specialist가 전문 클래스에 집중하면서 비전문 클래스의 지식을 유지하도록 범용 모델의 Soft Target을 함께 사용하는 방안을 제안한다. 앞 음향 실험을 근거로 한 향후 탐색이며, 이 절에서 완료된 JFT 검증 결과는 제시하지 않는다.

## 7 Mixture of Experts와의 관계

Mixture of Experts(전문가 혼합)는 전문가의 성능과 배정 네트워크가 서로 영향을 주면서 학습된다. 반면 이 논문의 Specialist는 범용 모델로 집합을 먼저 정한 뒤 각각 독립적으로 학습한다. 저자는 이 차이를 대규모 데이터에서 병렬 학습하기 쉬운 이유로 설명한다.

## 8 논의

숫자·음성 실험은 큰 모델이나 Ensemble의 예측 정보를 단일 모델로 전달할 수 있음을 보여준다. Specialist는 매우 큰 모델을 개선하는 별도의 방법으로 제시되지만, 그 지식을 단일 모델로 다시 옮기는 것은 아직 보이지 못했다고 결론에 명시한다. 이 구분이 논문의 검증 범위를 결정한다.
