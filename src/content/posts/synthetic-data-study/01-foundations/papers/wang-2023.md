## 초록

Instruction Tuning(지시문에 따른 수행을 학습하는 미세조정)에 필요한 사람이 쓴 자료의 비용·다양성 문제를 다룬다. Self-Instruct는 언어 모델이 지시문과 수행 예제를 생성하고, 부적절하거나 유사한 결과를 선별한 뒤 학습 자료로 사용하는 방법이다. 논문은 GPT-3로 데이터를 만들고 같은 모델을 학습하여 새로운 과제에서의 수행을 평가한다.

## 1 서론

여러 과제를 지시문으로 표현해 학습시키면 새 과제 수행을 유도할 수 있지만, 사람의 과제 설계에 계속 의존하면 비용과 범위가 병목이 된다. 저자는 모델의 기존 능력으로 추가 지시문 자료를 구성하는 Bootstrapping(초기 자원에서 결과를 확장하는 반복 과정)을 제안한다. 연구 질문은 아무 근거 없이 참된 정보를 새로 발견할 수 있는지가 아니라, 생성한 수행 예제로 지시 이행을 개선할 수 있는지다. [원문 §1](https://arxiv.org/html/2212.10560v2#S1)

<figure class="paper-figure" id="figure-1"><a href="https://arxiv.org/html/2212.10560v2/teaser_examples.png" target="_blank" rel="noopener"><img width="467" height="718" src="https://arxiv.org/html/2212.10560v2/teaser_examples.png" alt="Figure 1: 모델이 생성한 지시문·예제" loading="lazy" /></a><figcaption>Figure 1. 모델이 생성한 지시문·예제 <a href="https://arxiv.org/html/2212.10560v2#S1.F1">원문</a></figcaption></figure>

정형적인 분류 과제에 한정하지 않고 다양한 사용자 요구를 생성하는 모습을 보여준다. 지시문과 그 수행 예제를 함께 읽어야 무엇을 학습 자료로 만드는지 알 수 있다. 제시된 성공 사례가 전체 데이터의 품질을 대표하는 것은 아니며, 그 점은 §3.3의 검토 결과에서 확인한다.

## 2 방법

이 절은 새 과제를 출제하는 단계와 모델을 학습하는 단계를 나눈다. 데이터 생성 중 과제 풀이 확대되지만, 그때마다 모델 가중치를 갱신하는 구조로 설명되지는 않는다.

소수의 시드에서 새 지시문과 예제를 생성하고, 낮은 품질이나 중복을 걸러 과제 저장소에 되돌려 넣는 흐름이다. 그림의 되먹임은 데이터 풀 확장을, 마지막 학습 단계는 만들어진 데이터로 원래 모델을 미세조정하는 과정을 뜻한다. 매번 생성할 때마다 모델 가중치를 갱신하는 것으로 혼동하지 않는다.

### 2.1 지시문 데이터의 정의

한 과제는 Instruction(지시문)과 하나 이상의 Input(입력)–Output(출력) 예제로 구성된다. 원문의 $M(I, X) = Y$는 모델이 지시 I와 입력 X를 받아 목표 Y를 내도록 학습한다는 뜻이다. 품질을 측정하는 공식이나 완벽한 정답 보장이 아니다.

별도 입력이 없는 지시문도 허용한다. 과제 내용 일부가 지시문에 들어갈지 입력에 들어갈지는 고정되지 않으므로, 형식 다양성을 막지 않는 정의다. [원문 §2.1](https://arxiv.org/html/2212.10560v2#S2.SS1)

### 2.2 지시문 데이터의 자동 생성

#### 지시문 생성

사람이 작성한 175개 Seed Task(초기 과제)에서 시작한다. 과제 풀에서 고른 지시문을 예시로 주고 새 지시문을 생성한다. 사람의 예제와 앞서 생성한 예제를 함께 쓰는 것은 초기 품질 기준을 유지하면서 범위를 확장하려는 선택이다.

#### 분류 과제 판별

생성한 지시문이 유한한 출력 라벨을 가진 Classification(분류)인지 판별한다. 이후 생성 순서를 달리하기 위한 단계이며, 과제 유형 판정에도 모델을 사용한다.

#### 수행 예제 생성

일반 과제에는 Input-first(입력 우선 생성)를 사용해 입력을 만든 뒤 출력을 생성한다. Classification에서는 이 순서가 특정 라벨에 편중된 입력을 만들 수 있어 Output-first(출력 우선 생성)로 라벨부터 정하고 해당 입력을 만든다. 생성 순서는 형식 취향이 아니라 라벨 편향에 대응하는 설계다.

#### 필터링과 후처리

ROUGE-L(최장 공통 부분수열에 기반한 텍스트 겹침 지표)로 기존 지시문과 지나치게 유사한 것을 제외한다. 처리하기 어려운 과제, 중복 예제, 같은 입력에 상충하는 출력, 길이·반복 등의 이상도 규칙으로 거른다. 이러한 규칙은 노이즈를 줄이지만 모든 출력의 의미적 정답성을 증명하지는 않는다. [원문 §2.2](https://arxiv.org/html/2212.10560v2#S2.SS2)

### 2.3 지시문 수행을 위한 미세조정

지시문과 입력을 연결해 프롬프트를 만들고 출력 부분을 생성하도록 Supervised Learning(지도학습)을 수행한다. 접두어나 줄바꿈 등 표현 형식을 다양하게 하여 하나의 템플릿에만 의존하지 않도록 한다. 앞에서 확장한 과제 풀이 실제 가중치 학습에 쓰이는 시점이 이 절이다.

## 3 GPT-3가 생성한 데이터

### 3.1 통계

GPT-3의 davinci 엔진으로 생성·선별한 자료는 약 5만 2천 개 지시문과 8만 2천 개 수행 예제다. 한 과제에 여러 예제가 있을 수 있으므로 지시문 수와 예제 수를 구분한다. 이 절은 실험에 사용한 데이터의 규모를 확정한다.

| 항목 | 값 |

### 3.2 다양성

동사–목적어 구조, Seed Task와의 ROUGE-L 겹침, 지시문·입력·출력의 길이를 조사한다. 서로 다른 표현과 의도가 생성됨을 보여 주지만, 표현 통계만으로 가능한 모든 능력이 고르게 포함되었다고 증명하는 것은 아니다. [원문 §3](https://arxiv.org/html/2212.10560v2#S3)

<figure class="paper-figure" id="figure-3"><a href="https://arxiv.org/html/2212.10560v2/instruction_sunburst_v2.png" target="_blank" rel="noopener"><img width="236" height="245" src="https://arxiv.org/html/2212.10560v2/instruction_sunburst_v2.png" alt="Figure 3: 생성 지시문의 동사·목적어 분포" loading="lazy" /></a><figcaption>Figure 3. 생성 지시문의 동사·목적어 분포 <a href="https://arxiv.org/html/2212.10560v2#S2.F5">원문</a></figcaption></figure>

안쪽 고리는 자주 쓰이는 동사, 바깥 고리는 해당 동사와 연결된 목적어다. 분류·생성 요구의 범위를 시각적으로 보여주지만, 이러한 문장 구조를 가진 지시문은 전체의 14%이므로 모든 지시문의 의미 다양성을 이 그림만으로 판단할 수 없다.

<figure class="paper-figure" id="figure-4"><a href="https://arxiv.org/html/2212.10560v2/overlap_with_seed_instructions.svg" target="_blank" rel="noopener"><img width="191" height="46" src="https://arxiv.org/html/2212.10560v2/overlap_with_seed_instructions.svg" alt="Figure 4: 생성 지시문과 가장 비슷한 시드의 ROUGE-L 분포" loading="lazy" /></a><figcaption>Figure 4. 생성 지시문과 가장 비슷한 시드의 ROUGE-L 분포 <a href="https://arxiv.org/html/2212.10560v2#S2.F5">원문</a></figcaption></figure>

각 생성 지시문을 가장 유사한 시드와 비교한 표면적 중복 분포다. 시드 문장을 그대로 반복했는지 확인하는 데 도움이 되지만, ROUGE-L이 낮다고 과제 의미까지 새롭다고 단정할 수는 없다.

### 3.3 품질

표본 지시문과 수행 예제를 사람이 검토한다. 저자는 지시문 자체보다 입력·출력 예제에 더 많은 오류가 남는다고 보고한다. 일부 오류가 있어도 형식과 부분적으로 올바른 수행 신호가 학습에 도움이 될 수 있다고 해석한다. 이는 오류 데이터가 언제나 유익하다는 일반 명제가 아니라 뒤의 학습 결과와 연결한 설명이다.

**Table 2. 생성 데이터의 사람 검토** ([원문](https://arxiv.org/html/2212.10560v2#S3.T2)). 원문 검토 항목을 한국어로 요약했다.

| 검토 항목 | 유효하다고 판단한 비율 |
| --- | ---: |
| 지시문이 유효한 과제를 설명하는가 | 92% |
| 입력이 지시문에 적절한가 | 79% |
| 출력이 정확하고 수용 가능한 응답인가 | 58% |
| 모든 필드가 유효한가 | 54% |

지시문 자체의 유효성과 정답의 정확성을 분리하면, 읽기 좋은 지시문을 생성하는 것만으로 학습 데이터 품질이 확보되지 않음을 볼 수 있다. 이 비율은 논문에서 검토한 표본의 결과이며 데이터 전체를 전수 판정한 수치는 아니다.

## 4 실험 결과

### 4.1 자기 생성 데이터로 학습한 GPT-3

생성 데이터를 사용해 원래의 davinci를 미세조정한다. 보고된 설정은 출력에 학습을 집중하도록 prompt loss weight를 0으로 두고 두 차례 반복 학습하는 것이다. 데이터 생성 모델과 학습 대상이 같다는 점이 이미 지시 학습된 강한 교사의 응답을 모으는 방식과 구별된다.

### 4.2 기준선

#### 사전학습 모델

추가 지시 학습 없는 GPT-3와 T5 계열을 비교해, 사전학습만으로 지시를 수행하는 정도를 확인한다.

#### 공개 지시 학습 모델

T0와 Tk-Instruct를 비교한다. 이들은 다른 기반·학습 자료를 사용하므로, 모든 차이를 합성 데이터 하나에 귀속하기보다는 공개 지시 수행 모델과의 위치를 보여주는 비교로 읽는다.

#### 지시 학습된 GPT-3

동일한 GPT-3를 공개 데이터로 미세조정한 조건과 InstructGPT를 함께 비교한다. SuperNI에서는 시험 자료 노출 가능성 때문에 비교할 InstructGPT 버전을 제한했다고 설명한다. 비교군의 버전 선택 자체가 평가의 독립성과 연결된다. [원문 §4.2](https://arxiv.org/html/2212.10560v2#S4.SS2)

| GPT-3 + SuperNI Training | 175B | SuperNI 학습 포함 | 49.5 |
| GPT-3 Self-Inst + SuperNI Training | 175B | SuperNI 학습 포함 | 51.6 |

같은 GPT-3의 기본값과 Self-Inst를 비교하면 합성 지시 학습의 효과를 볼 수 있다. SuperNI 학습 자료를 사용한 행은 조건이 다르므로 별도 묶음으로 읽어야 한다. ROUGE-L은 이 평가의 응답 중복 지표이며 사람 평가의 성공 비율과 동일하지 않다.

#### 결과

저자는 원래 GPT-3보다 지시 수행이 크게 나아지고 일부 기준선과 경쟁하는 결과를 보고한다. SuperNI 학습 데이터로 학습한 모델의 이점도 나타나므로, 같은 분포의 자료와 새로운 생성 자료가 제공하는 효과를 구분해야 한다.

### 4.4 사용자 지향의 새로운 지시문에서 평가

앞의 평가가 전통적인 언어처리 과제에 치우칠 수 있어, 저자들은 실제 사용을 상정한 252개 지시를 별도로 만든다. 사람은 응답을 만족스러운 답, 사소한 오류가 있는 답, 관련은 있으나 큰 오류가 있는 답, 부적절한 답으로 나눈다.

서로 다른 모델의 응답을 네 등급으로 나누어 비교한다. 응답의 정확성과 지시 수행 정도를 사람이 평가한 결과이며, SuperNI의 ROUGE-L과는 다른 평가다. 공개 지시 데이터로 학습한 GPT-3 변형들과의 차이, InstructGPT 계열과 남는 차이를 구분해서 읽는다.

#### 사람 평가 설정

과제 작성자가 모델 정보를 가린 응답을 판단한다. 다양한 과제에 동일한 자동 점수를 적용하기 어렵다는 문제에 대한 대응이다. 단순 문장 유사도보다 실제 지시 수행 여부를 보려는 단계다.

#### 결과

생성 자료로 학습한 GPT-3가 공개 지시 데이터 기반 비교군보다 우수한 결과를 보인다. InstructGPT와의 차이는 어떤 평가 등급을 허용 가능한 답으로 묶는지와 비교 버전에 따라 해석해야 한다. 이 결과는 모든 현대 모델에 대한 순위를 의미하지 않는다.

### 4.5 데이터 규모와 품질의 영향

<figure class="paper-figure" id="figure-7"><a href="https://arxiv.org/html/2212.10560v2/data_scaling_plot.svg" target="_blank" rel="noopener"><img width="476" height="388" src="https://arxiv.org/html/2212.10560v2/data_scaling_plot.svg" alt="Figure 7: 학습 지시문 수와 응답 품질의 영향" loading="lazy" /></a><figcaption>Figure 7. 학습 지시문 수와 응답 품질의 영향 <a href="https://arxiv.org/html/2212.10560v2#S4.F7">원문</a></figcaption></figure>

가로축은 로그 눈금의 학습 지시문 수이며 가장 작은 조건은 175개 시드만 사용한다. 원래 생성 응답과 InstructGPT-003으로 개선한 응답을 비교하여, 데이터 양과 정답 품질을 함께 살핀다. 교사를 바꾼 품질 개선을 순수한 데이터 개수 효과로 해석하지 않는다.

#### 데이터 규모

생성 데이터의 일부만 사용해 모델을 학습하고 사용자 지향 평가에서 비교한다. 자료가 늘면 개선되지만 증가 폭이 둔화한다. SuperNI와 사용자 지향 평가의 포화 시점도 달라, 생성량의 효과가 목표 평가 분포에 의존함을 시사한다.

#### 데이터 품질

지시문·입력은 유지하고 더 강한 InstructGPT-003으로 출력만 다시 생성한 뒤 학습한다. 저자는 이 조건의 개선을 보고하여, 과제 종류를 늘리는 것과 목표 출력 품질을 높이는 것이 서로 다른 개선 경로임을 보여준다. 이 변형은 원래의 자기 생성 설정에 외부 교사 신호를 추가한 경우다. [원문 §4.5](https://arxiv.org/html/2212.10560v2#S4.SS5)

## 5 관련 연구

### 지시를 따르는 언어 모델

사람이 쓴 지시문 자료로 여러 과제를 학습하는 선행 연구를 정리한다. Self-Instruct의 차이는 그 자료를 어떻게 더 넓고 저렴하게 얻을지에 있다.

### 언어 모델을 통한 생성과 증강

특정 과제의 예제를 늘리는 기존 접근과 달리 새로운 과제 정의까지 생성한다. 동시에 진행된 지시문 생성 연구와는 시드의 출처·생성 모델·파이프라인이 다르다고 설명한다.

### 지시문 생성

주어진 예제에서 기존 과제의 설명을 추론하는 것과, 지시문 및 수행 예제를 함께 만들어 새 과제를 확장하는 차이를 짚는다.

### 모델 자기 학습

Self-training(예측을 이용한 자기 학습)은 흔히 정해진 과제의 미라벨 입력에 라벨을 붙인다. Self-Instruct는 과제와 입력의 구성까지 생성한다는 점에서 범위가 다르다.

### 지식 증류

Knowledge Distillation(지식 증류)과의 공통점은 모델 신호를 다시 학습한다는 것이다. 원래 설정에서는 교사와 학생이 같은 모델이며, 전달 단위가 지시문과 예제의 묶음이라는 차이를 둔다.

### 제한된 자원에서의 반복 확장

소량의 초기 자료나 모델의 예측을 재활용하는 연구들과 연결한다. Self-Instruct는 그 중에서도 새로운 지시 과제의 확장을 목표로 한다.

### 멀티모달 지시 수행

다른 입력 유형에 대한 지시 학습으로 확장할 가능성을 언급한다. 본 논문에서 해당 실험을 완료한 것은 아니며 향후 과제로 남긴다.

## 6 결론

저자는 자기 생성 지시 데이터가 GPT-3의 지시 수행 개선에 도움이 된다는 결과와 공개 데이터의 가치를 정리한다. 이 방법을 최종 완성된 정렬 체계보다 후속 개선을 위한 출발점으로 제시한다.

## 7 폭넓은 영향

공개되지 않은 상용 모델의 학습 과정을 이해하기 어려운 상황에서, 공개 지시문 데이터가 연구의 투명성과 접근성을 높일 수 있다고 설명한다. 이것은 개별 평가 성능과 별개인 연구 인프라 측면의 의의다.

## 8 한계

### 드문 현상

모델이 사전학습에서 자주 본 과제에 개선이 집중될 수 있으며, 드물고 창의적인 지시에 취약할 수 있다고 지적한다. 생성 자료가 기존 모델의 분포를 물려받는 문제다.

### 큰 모델에 대한 의존

방법의 성공이 큰 모델의 능력에 의존할 가능성이 있어, 작은 연구자의 계산 자원 접근성을 제한할 수 있다고 설명한다. 이 논문이 다양한 모델 크기의 효과를 모두 입증한 것은 아니다.

### 모델 편향의 강화

반복 생성이 사회적 편향과 라벨 불균형을 확대할 수 있다고 경고한다. 데이터가 자동으로 늘어난다는 성질이 그 자체로 안전성이나 대표성을 보장하지 않는다는 한계다. [원문 §8](https://arxiv.org/html/2212.10560v2#S8)

### B.2 평가자 일치도

Cohen’s Kappa(우연 일치를 보정한 범주 평가 일치도)와 순위 상관으로 평가자의 판단 관계를 확인한다. 범주 구분과 허용 가능한 응답의 이분 구분은 서로 다른 일치도를 낼 수 있다. 원문 본문과 부록의 네 등급 kappa 표기에는 작은 차이가 있어 이 해설은 단일 수치로 통합하지 않는다.

### B.3 모델 응답 예시

등급별 실제 모델 출력을 보여준다. 지시와 관련된 풀이가 길어도 최종 내용이 틀리면 낮은 평가를 받을 수 있어, 수행 시도와 정확한 완수를 구분하는 사례다.

## 부록 C 생성 과제와 수행 예제

올바른 예제와 오류가 있는 예제를 구분해 제시한다. 지시문·입력·출력 중 어느 부분이 문제인지 표시함으로써 §3의 품질 평가를 구체화한다. 독자는 생성 결과가 형식적으로 그럴듯한지와 실제로 맞는지를 나누어 확인할 수 있다. [원문 부록](https://arxiv.org/html/2212.10560v2#A1)
