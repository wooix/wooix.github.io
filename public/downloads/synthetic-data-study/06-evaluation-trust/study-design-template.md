# 합성데이터스터디 · 최종 연구설계 양식

이 문서를 복사해 한 연구의 계획과 결과를 기록합니다. 1강의 학습 목표, 2강의 생성 설계, 3강의 큐레이션, 4강의 실행 검증, 5강의 추론·에이전트 기록을 하나의 평가 설계로 연결합니다. 예제 수, 통과율, 성능, 비용 등의 결과는 미리 채우지 않았습니다.

- `[작성]`은 작성할 내용, `미정`은 아직 결정하지 않은 계획입니다.
- `미측정`은 측정하지 않은 값, `미실행`은 실행하지 않은 단계, `미확인`은 근거가 부족한 판단입니다. 이를 0·실패·통과로 바꾸지 않습니다.
- 적용하지 않는 항목은 `해당 없음 — 이유: [작성]`으로 표시합니다. 분모가 없거나 지표가 정의되지 않으면 `계산 불가 — 이유: [작성]`로 남깁니다.
- 계획은 실행 전에 판본을 남기고, 변경 시 이유와 영향 범위를 기록합니다. 예상 결과와 창작 예시는 실측 결과에 합산하지 않습니다.
