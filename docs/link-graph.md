# 글 연결 그래프

모든 페이지의 오른쪽 아래 **글 연결**을 누르면 전체 그래프와 Backlinks(역방향 링크)를 볼 수 있습니다. **크게 보기**는 선택한 탭을 유지한 채 전체 화면을 엽니다. 기존 본문, 왼쪽 탐색, 목차와 검색은 그대로 사용합니다.

## 무엇을 연결하나요?

노드는 `getPosts()`가 반환하는 공개 글입니다. Draft(초안)와 게시일이 미래인 글은 노드와 연결 모두에 포함하지 않습니다. 공개 글의 Astro `rendered.html`, 즉 Markdown과 본문 HTML을 렌더링한 결과에 실제로 존재하는 내부 `<a href>`만 연결로 읽습니다. `parse5`로 HTML 구조를 분석하며, 정규식으로 본문 링크를 추출하지 않습니다.

- `A → B`는 A의 본문이 B를 링크한다는 뜻입니다. B가 A도 링크하면 반대 방향을 별도 연결로 유지하고 서로 다른 곡선으로 표시합니다.
- 같은 A → B가 여러 번 나오면 하나로 합칩니다. 자기 자신과 같은 글의 섹션을 가리키는 링크는 생략합니다.
- 본문의 접힌 `<details>` 안에 있는 읽기 목록도 실제 링크이므로 포함합니다.
- Code Block(코드 블록), Inline Code(인라인 코드), HTML 주석, `script`, `style`, `template`, `textarea` 안의 예시 링크는 제외합니다.
- `parentPost`는 Breadcrumb(상위 경로) 정보입니다. 연결을 만들지 않습니다. 왼쪽 탐색, 자동 관련 글, 이전·다음 글, 목차, 메뉴도 연결을 만들지 않습니다.
- 같은 연구 분야라는 이유로 연결을 만들지 않습니다. 연결이 없는 글도 전체 그래프에 표시합니다.

`Backlinks(역방향 링크)`에는 **현재 글과 현재 글을 본문에서 링크한 글**, 그리고 그 방향의 연결만 표시합니다. 현재 글에서 나가는 연결이나 유입 글끼리의 연결은 표시하지 않습니다. 유입이 없으면 그 상태와 현재 글을 보여 줍니다. 홈·분야·아카이브처럼 개별 글이 아닌 페이지에서는 안내 문구를 보여 줍니다.

## 글에서 링크하는 방법

기존 공개 URL을 그대로 사용합니다. 파일을 옮기거나 Frontmatter(머리말 메타데이터)에 연결 필드를 추가할 필요가 없습니다.

```md
[기초 개념 읽기](/notes/knowledge-distillation-foundations/)
[강의로 돌아가기](/notes/synthetic-data-study/01-foundations/#references)
```

`https://wooix.github.io/notes/.../`와 `//wooix.github.io/notes/.../`도 지원합니다. `../다른-글/` 같은 상대 링크는 **게시된 현재 글 URL**을 기준으로 해석합니다. Hash(섹션 식별자)와 Query(질의 문자열)는 같은 글로 합칩니다. `.md` 원고 파일 경로는 공개 글 URL이 아니므로 지원하지 않습니다.

출처 사이트는 `https://wooix.github.io`입니다. 외부 호스트, 다른 Protocol(통신 규약)·Port(포트), 로그인 정보가 포함된 URL, 비 HTTP 링크, 이미지·PDF·원고 파일, 잘못 인코딩한 경로는 제외합니다. 정규화된 ID가 실제 공개 글 목록에 있어야 연결이 생깁니다. 비공개 대상을 가리키는 본문 링크가 있어도 그래프 데이터에 해당 대상 정보를 추가하지 않습니다.

## 조작과 접근성

- 탭은 클릭하거나 방향키·Home·End로 전환합니다. Tab으로 버튼, 노드 링크, 글 목록에 이동하고 Enter로 글을 엽니다.
- 노드에 마우스를 올리거나 초점을 두면 그래프 아래에 전체 제목과 분야를 표시합니다. 별도 **글 목록**에서도 제목을 읽고 이동할 수 있습니다.
- 현재 글은 테두리와 **현재 글** 텍스트로 구분합니다. 분야 색상은 `src/data/graph-topics.ts`의 분야 ID에 고정하며 탭이나 페이지가 바뀌어도 같습니다. 범례와 목록에 분야 이름을 함께 표시합니다.
- 확대·축소·원위치 버튼을 사용할 수 있습니다. 그래프의 빈 공간을 드래그하면 이동합니다. 그래프 밖에서는 패널을 스크롤할 수 있습니다.
- Escape는 패널 또는 전체 화면을 닫고 열었던 버튼으로 초점을 돌려줍니다. 전체 화면은 사이트의 기존 Native Dialog(기본 대화상자) 관리와 검색 단축키를 공유합니다.
- 모바일 목차 버튼과 겹치지 않도록 글 연결 버튼을 그 위에 배치합니다.

## 데이터와 실행 범위

데이터는 빌드 중에 생성하여 HTML에 JSON으로 넣습니다. 외부 그래프 API, CDN 스크립트, 별도 데이터 요청이 없습니다. JSON 안의 `<`는 이스케이프하고, 클라이언트의 제목은 `textContent`로 표시합니다. 공개 글에 렌더링 결과가 없으면 빌드가 명시적으로 실패합니다. 실제 빈 본문은 허용합니다. 클라이언트 초기화 실패 안내는 연결이 없는 상태와 구분합니다.

배치는 같은 입력과 크기에 대해 결정적입니다. 70개 이하 노드는 130회, 180개 이하 노드는 45회 힘 계산을 하고 멈춥니다. 더 큰 목록은 결정적인 초기 배치를 사용합니다. 지속적인 애니메이션·시뮬레이션은 없으며, 화면 크기나 탭이 바뀔 때만 다시 계산합니다. 현재 글 18편 기준으로 전체 방향 연결 24개, 고립 글 5편입니다. 이 수치는 원고의 실제 링크에 따라 변합니다.

## 구현과 검증

- 본문 추출: `src/lib/link-graph-source.ts`
- URL·방향 처리: `src/lib/link-graph.ts`
- 배치: `src/lib/link-graph-layout.ts`
- 공개 글 연결: `src/lib/site-graph.ts`
- UI: `src/components/LinkGraph.astro`, `GraphView.astro`, `src/scripts/link-graph.ts`, `src/styles/link-graph.css`
- 테스트: `npm run test:graph`. 배포에서도 `check`, `test:navigation`, `test:graph`, `build` 순서로 확인합니다.

새 글을 공개한 뒤 `npm run build`를 실행하면 노드와 본문 연결이 자동으로 갱신됩니다. Graph(그래프)는 현재 게시된 본문 링크의 탐색 도구이며, 인용 수나 연구 중요도 평가를 뜻하지 않습니다.
