# 학습 타이머

개별 글의 `post.data.readingTime`을 그대로 분 단위 시작 시간으로 사용합니다. 읽기 시간 계산법과 원고는 바꾸지 않습니다. 홈·주제·아카이브에는 타이머를 표시하지 않습니다.

타이머는 처음 실제로 아래로 스크롤할 때 나타나 `[HH:MM:SS:mmm]`으로 줄어듭니다. 최초 표시 때 화면 네 변에 짧은 효과를 한 번 표시하며, 동작 줄이기 설정에서는 생략합니다. 일시정지·계속하기·다시 시작을 제공하고 다시 시작은 원래 전체 시간부터 즉시 진행합니다. 0에서는 완료 상태로 멈춥니다.

시작은 신뢰된 아래 방향 휠, 위로 밀어 문서를 내리는 터치, PageDown·ArrowDown·Space·End 입력을 짧게 기록한 뒤 실제 `window.scrollY` 증가를 확인합니다. 입력란·버튼·대화상자·내부 스크롤 영역의 입력은 제외합니다. 네이티브 스크롤바는 문서 루트의 gutter 또는 overlay 끝 영역에 실제 포인터 입력이 전달된 경우만 같은 확인을 거칩니다. 일반 본문 클릭·페이지 복원·앵커 이동·프로그램 스크롤 자체만으로 시작하지 않습니다. 스크롤바 입력을 DOM에 전달하지 않는 환경에서는 휠·터치·스크롤 키를 사용합니다.

시간 계산은 `Date.now()` 기준 종료 시각을 사용합니다. 실행 중 숨겨진 탭과 기기 절전에서 지난 시간도 포함하며, 일시정지한 시간은 제외합니다. 시스템 시계를 바꾸면 그 wall-clock(실제 시각) 변경의 영향을 받습니다. 입력과 스크롤의 짧은 상관관계에는 단조로운 `performance.now()`를 사용합니다.

화면의 밀리초는 매 프레임 갱신하며 매 밀리초마다 콜백을 실행하지 않습니다. 숨김·일시정지·완료 상태에서는 RAF(프레임 갱신)를 멈추고, 탭 복귀 시 종료 시각으로 다시 계산합니다. 스크린리더에는 시작·정지·재개·다시 시작·완료만 알립니다. 상태는 현재 문서 안에만 있으며 새 글이나 새로고침에서는 새 타이머입니다.

구현은 `StudyTimer.astro`, `src/scripts/study-timer.ts`, `src/lib/study-timer.ts`, 전용 `study-timer.css`입니다. `npm run test:timer`로 시간·완료·재시작·입력 확인의 핵심 조건을 검사하고 배포 CI에서도 실행합니다.
