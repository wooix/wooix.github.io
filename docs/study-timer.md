# 학습 타이머

개별 글의 `post.data.readingTime`을 그대로 분 단위 시작 시간으로 사용합니다. 읽기 시간 계산법과 원고는 바꾸지 않습니다. 홈·주제·아카이브에는 타이머를 표시하지 않습니다.

문서를 처음 아래로 스크롤하면 타이머가 나타나 `[HH:MM:SS:mmm]`으로 줄어듭니다. 휠·터치·스크롤바·키보드 등 입력 종류를 추정하지 않고 `window.scrollY` 증가를 확인합니다. 일반 글에는 시작 대기시간이 없으며, hash(문서 내 위치) 이동과 뒤로가기 위치 복원에만 500ms 동안 기준 위치를 다시 잡습니다. 내부 패널의 스크롤은 문서 스크롤로 간주하지 않습니다.

시작·계속하기·다시 시작 때마다 화면 전체에 450ms의 부드러운 코랄 빛을 표시하고 타이머를 약 1초간 강조합니다. 기존 효과를 먼저 취소하여 겹쳐 재생하지 않습니다. 동작 줄이기 설정에서는 화면 효과 대신 타이머에 900ms 동안 고정 테두리를 표시합니다. 효과는 포인터 입력을 가로채지 않습니다. 실행 중 일반 스크롤로 효과를 반복하거나, 일시정지 중 스크롤로 타이머를 재개하지 않습니다. 다시 시작은 원래 전체 시간부터 즉시 진행하고 0에서는 멈춥니다.

시간 계산은 `Date.now()` 기준 종료 시각을 사용합니다. 실행 중 숨겨진 탭과 기기 절전에서 지난 시간도 포함하며, 일시정지한 시간은 제외합니다. 시스템 시계를 바꾸면 그 wall-clock(실제 시각) 변경의 영향을 받습니다. 위치 복원의 짧은 제외 구간에만 `performance.now()`를 사용합니다.

밀리초 표시는 매 프레임 갱신하며 숨김·일시정지·완료 상태에서는 RAF(프레임 갱신)를 멈춥니다. 탭 복귀 시 종료 시각으로 다시 계산합니다. 스크린리더에는 상태 변화만 알립니다. 상태는 현재 문서 안에만 있으며 새 글이나 새로고침에서는 새 타이머입니다.

구현은 `StudyTimer.astro`, `src/scripts/study-timer.ts`, `src/lib/study-timer.ts`, 전용 `study-timer.css`입니다. 전체 화면 효과는 `BaseLayout.astro`에서 `body` 바로 아래에 배치합니다. `npm run test:timer`로 시간·완료·재시작·스크롤 시작 조건을 검사하고 배포 CI에서도 실행합니다.
