# 개인 메모와 문장 표시

모든 `/notes/` 글의 오른쪽 아래 `메모` 버튼에서 사용할 수 있습니다. 본문 문장을 선택하면 메모 패널이 열립니다. 노랑·초록·파랑·분홍·보라 중 하나를 골라 형광펜 또는 밑줄을 적용합니다. 선택 문장에 의견을 추가하거나, 선택 해제 후 독립된 의견을 작성할 수 있습니다. 자유 메모와 작성 중인 의견도 입력 즉시 저장됩니다. 저장 목록에서 의견 수정과 항목 삭제가 가능합니다.

저장 위치는 현재 origin의 localStorage이며 글 경로별로 분리합니다. 서버 전송이나 기기 간 자동 동기화는 없습니다. 브라우저 데이터를 지우면 기록도 삭제되므로 `이 글 백업`으로 JSON 파일을 보관할 수 있습니다. 같은 글에서 백업을 가져오면 기존 기록에 병합합니다. 저장이 실패하면 패널에 안내합니다.

표시는 텍스트 위치·선택 문장·앞뒤 문맥으로 복원합니다. 본문 수정으로 위치가 달라지면 문장과 문맥을 다시 찾고, 모호하거나 없어진 문장은 목록에 보존하되 잘못된 위치에 표시하지 않습니다. 수식 내부의 표시는 수식 구조를 보존하기 위해 건너뛰며, 선택 문장 자체는 저장합니다.

검증: `npm run check`, `npm run test:navigation`, `npm run test:graph`, `npm run test:timer`, `npm run build`. 브라우저에서는 문장 선택, 겹치는 형광펜·밑줄, 색상, 의견 추가·수정·삭제, 새로고침 후 메모·의견 초안·표시 복원, 모바일 패널 너비를 확인합니다.
