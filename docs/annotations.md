# 본문 메모와 집중 읽기

글 본문의 문단 사이에 마우스를 올리면 `＋`가 나타납니다. 키보드 Tab으로도 접근할 수 있고 터치 화면에서는 항상 보입니다. 누르면 해당 문단 아래에 메모 블록이 생깁니다. 블록 안에서 바로 입력하며 자동 저장됩니다. 메모를 접거나 다시 펼칠 수 있습니다. 문장을 선택하는 것만으로 편집창이 열리지는 않습니다.

문장을 선택하고 오른쪽 클릭하면 밑줄·형광펜과 다섯 가지 색상을 선택할 수 있습니다. 기존 표시를 오른쪽 클릭하면 변경·삭제할 수 있습니다. 링크와 입력란에서는 브라우저 기본 메뉴를 유지합니다. 수식 내부는 표시로 DOM 구조를 바꾸지 않습니다.

새 기록은 글 경로별 `wooix-reading-v2` localStorage에 저장됩니다. 이전 메모 형식은 읽거나 이전하지 않습니다. 서버 전송·기기 간 동기화는 없습니다. 글 끝의 `내 메모 · 백업`에서 JSON을 내려받거나 같은 글의 새 형식 백업을 병합할 수 있습니다. 브라우저 저장소를 지우면 메모도 사라집니다. 본문 내용과 절 정보로 위치를 확인하며, 위치를 찾지 못한 메모는 백업 영역에 보존합니다.

글 상단의 `집중해서 읽기`에서 시간과 읽기 목표를 정합니다. Focus Mode(집중 모드)는 탐색·목차·연결 그래프를 숨기고 본문과 메모를 남깁니다. 진행 막대만 기본 표시하며 `시간 보기`로 남은 시간을 확인합니다. 일시정지·계속 읽기·집중 종료를 지원합니다. 완료는 작은 상태 문구로 표시합니다. 종료하면 남은 시간은 일반 타이머에서 일시정지됩니다. 새로고침은 집중 세션을 종료하지만 메모는 유지됩니다.
